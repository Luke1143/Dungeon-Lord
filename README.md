# Dungeon Lord (GODHAND)

Dungeon-Keeper-style browser game. You are the Dungeon Lord: dig, build rooms, keep your horde happy, and fend off the heroes until you conquer the world portal.

- `index.html` - the game (single file for now, open it in a browser)
- `docs/godhand.md` - design document ("GODHAND": one verb, Interact)
- `CLAUDE.md` - working notes for Claude Code sessions
