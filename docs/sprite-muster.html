Sprite-Muster

Figuren sind 16×16 Pixel, Kacheln 32×32, beides mit gleich großen Pixeln gezeichnet. Eine Figur ist damit halb so breit wie eine Kachel, und vier passen auf ein Feld. Gezeichnet wird als Text im Code, nur die halbe Figur wird beschrieben (die andere Hälfte wird gespiegelt). Farben lassen sich pro Fraktion tauschen.
